# Neon for games247

games247's default theme: a synthwave look with a dusk sky, a striped retro sun, neon
mountains and a moving grid floor. The game list shows the selected game on a retro TV.

- Artwork is generated by the scripts in `tools/neon-theme/` (`make_svgs.py`, `make_floor.swift`
  and `make_layouts.py` for the per-aspect-ratio layouts).
- System logos, console pictures and system information are shared with the Linear theme
  (`linear-es-de`, MIT), which is always installed alongside this one.
- Font: [Orbitron](https://github.com/theleagueof/orbitron), SIL Open Font License 1.1
  (`assets/fonts/OFL.txt`).
- `capabilities.xml` uses the games247 `<fadeStyle>crt</fadeStyle>` extension: fade transitions
  are drawn as an old TV switching channels.
